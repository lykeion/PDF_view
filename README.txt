PDF 뷰어 · 로컬 PDF 리더

시작하기
이 폴더의 실행.cmd를 더블클릭하세요.
Google Chrome의 독립된 앱 창으로 열립니다. Chrome이 없으면 Microsoft Edge,
둘 다 없으면 기본 브라우저를 사용합니다.
로컬 뷰어는 .browser-profile 안의 전용 브라우저 프로필로 실행됩니다.
일반 Chrome이 이미 열려 있어도 제목 표시줄 없는 전체 화면으로 시작합니다.
바로가기와 실행 중인 작업표시줄에는 전용 고해상도 PDF 아이콘을 사용합니다.
최초 전환 시 이 뷰어의 마지막 PDF와 읽기 기록만 이전 브라우저에서 가져오며,
일반 Chrome의 로그인·방문 기록·설정은 복사하지 않습니다.
Chrome과 Edge에서는 전체 화면으로 시작하고, 마지막에 열었던 PDF와 읽던 쪽을
자동으로 복원합니다. 처음 실행하거나 복원할 파일이 없으면 책장을 보여줍니다.
PDF 표시는 브라우저 내장 뷰어가 아니라 Mozilla PDF.js가 담당합니다.
주소는 http://127.0.0.1:43187 입니다. 이 PC에서만 접속할 수 있습니다.
이 폴더 전체를 함께 유지하세요. index.html만 따로 열면 정상 동작하지 않습니다.

PDF 열기
왼쪽 책장의 유통관리사 PDF를 선택하거나, 책장 제목 오른쪽의 [PDF 열기]를 누르세요.
PDF를 창으로 끌어 놓아도 됩니다. 책장 위 검색은 파일 이름을 찾습니다.
책장에는 상위 작업 공간의 개념·기출·최빈출 원본 PDF 폴더가 표시됩니다.
목차는 [개념·기출·최빈출] → [과목 폴더] → [파일] 순서로 접고 펼칩니다.
폴더가 없는 파일은 카테고리 바로 아래에 표시됩니다.

내 자료와 목차 관리
책장의 [책장 관리]에서 PDF 여러 개 또는 폴더 전체를 등록합니다.
등록한 PDF는 user-data/books에 복사하고 목차는 user-data/catalog.json에 저장합니다.
폴더 등록 시 하위 폴더와 PDF의 구조를 함께 가져옵니다. 파일당 최대 1GB입니다.
목차를 추가하고 항목의 이름·상위 폴더·순서를 바꿀 수 있습니다.
[책장에서 제외]는 원본이나 보관 PDF를 삭제하지 않습니다. [제외한 항목 복원]에서 되돌립니다.
프로그램 업데이트와 재설치 시에도 user-data와 브라우저 프로필을 보존합니다.
등록한 자료를 다른 PC로 옮기려면 프로그램을 닫고 user-data 폴더 전체를 함께 복사하세요.
기존 기본 교재는 그대로 유지하며 [내 자료]에는 다른 시험·과목 자료도 자유롭게 등록합니다.

GitHub 프로그램 업데이트
책장의 [업데이트]에서 새 버전을 확인하고 [업데이트 후 다시 시작]을 누릅니다.
실행 후에도 한 번 새 버전을 확인해 업데이트 버튼에 표시합니다. 설치는 버튼을 눌러 진행합니다.
배포 저장소는 github.com/lykeion/PDF_view 입니다. PC에 Git을 설치할 필요는 없습니다.
프로그램 파일만 내려받아 검증·교체하므로 교재 PDF를 다시 받을 필요가 없습니다.
등록한 PDF·목차·브라우저 프로필·GPT 프로젝트 설정은 업데이트 대상에서 제외합니다.
적용 전 파일을 백업하고 새 서버가 정상적으로 시작되지 않으면 이전 프로그램으로 복구합니다.
처음 설치할 때는 GitHub Releases의 PDFViewer-setup.zip을 압축 해제하고 install.cmd를 실행합니다.
이 경량 설치파일에는 교재 PDF가 포함되지 않습니다. 기존 설치에 덮어 설치하면 교재를 유지합니다.

선택 영역으로 ChatGPT 질문
상단 [GPT 질문]을 누르고 한 페이지 안에서 질문할 부분을 드래그합니다.
선택한 부분을 원본 색상의 이미지로 준비하며, 질문 내용을 입력한 뒤
[ChatGPT에 입력하기]를 누르면 기존 Chrome의 ChatGPT 탭을 우선 사용합니다.
연결한 프로젝트에 이미지와 질문을 채우고, 전송 버튼은 직접 누릅니다.
ChatGPT 탭이 없으면 기존 브라우저에 프로젝트 탭을 엽니다.
[연결 프로젝트]에서 프로젝트 이름과 프로젝트 페이지 주소를 한 번 설정합니다.
프로젝트 연결 설정은 이 PC에만 저장됩니다. 다른 PC에서는 처음 한 번 설정합니다.
작성 중인 질문이 있으면 덮어쓰지 않습니다. 먼저 기존 질문을 전송하거나 비워 주세요.
자동 입력 중에는 Chrome에서 다른 창으로 전환하거나 키보드를 입력하지 마세요.
로그인이나 입력란 확인에 실패하면 안내와 이미지/질문 복사 버튼을 제공합니다.
ChatGPT 웹 화면이 바뀌면 자동 입력 연동을 다시 조정해야 할 수 있습니다.
질문한 영역의 임시 이미지는 전달을 마친 뒤 삭제합니다.
한 쪽/두 쪽, 페이지 크기 기준, 표지 따로 보기도 자동 저장하며 다음 실행에 유지합니다.

크게 읽기
목차에서 파일을 선택하면 현재 창 상태로 문서만 열립니다. 목차와 도구도 그대로 유지합니다.
PDF 열기와 끌어놓기도 전체화면을 자동으로 켜지 않습니다. F11 또는 전체보기 버튼으로 전환합니다.
[도구] 버튼을 누르면 목차와 배율 조작 도구를 다시 사용할 수 있습니다.
문서 이름은 Windows 창의 제목 표시줄에 표시됩니다. 별도 상단 헤더는 없습니다.
한 줄 도구막대의 왼쪽에는 보기·배율, 중앙에는 페이지 번호와 이전/다음,
오른쪽에는 색상·추가 보기 설정이 있습니다. 각 조작부는 버튼과 테두리로 구분됩니다.
좁은 창에서는 도구막대를 가로로 스크롤하면 나머지 도구가 보입니다.
색상 선택 상자 왼쪽의 [색상] 버튼으로 배경·글자·강조색 설정을 엽니다.
선택 상자의 [사용자 색]은 마지막으로 직접 조절한 색을 불러옵니다.
다른 기본 색상으로 전환하거나 프로그램을 다시 열어도 사용자 색은 따로 보관됩니다.
[⋯] 추가 보기 설정의 [화질 조절]을 펼치면 선명도·가는 획·농도·배경 정리가 있습니다.
[여백]에는 화면/너비 맞춤, 같은 크기/같은 높이/원본 비율, 여백 조절이 있습니다.
[⋯] 추가 보기 설정에서는 표지 따로 보기·회전·단축키 도움말을 사용할 수 있습니다.
Esc 키 또는 [나가기]로 전체 화면을 끝내고 일반 화면으로 돌아옵니다.
실행 직후의 전체 화면에서도 Esc를 누르면 최소화·최대화·닫기 버튼이 있는
제목 표시줄을 복원하고 최대화된 일반 창으로 돌아옵니다.
브라우저에서 전체 화면 진입을 허용하지 않으면 [전체 화면] 버튼을 눌러 주세요.
F11은 PDF 전체보기로 전환합니다.
제목 표시줄·목차·도구를 숨기며, 다시 F11 또는 Esc/[나가기]로 해제합니다.
프로그램 창을 닫으려면 Alt+F4를 누르세요.
전체 화면 아래 가운데에는 현재 페이지 범위와 전체 페이지 수가 반투명하게
표시됩니다. 두 쪽은 [1–2 / 35], 한 쪽은 [35 / 35]처럼 표시합니다.
일반 창에서 PDF 아래에 붙던 개별 쪽수와 하단 상태 줄은 표시하지 않습니다.
오른쪽 아래에는 한국 시간(Asia/Seoul)을 24시간제 시:분으로 표시합니다.
시간 옆 [기출 풀기]는 현재 읽는 장의 레일노트 문제를 엽니다.
바탕화면/시작 메뉴에 설치한 railnote 앱이 있으면 그 앱과 프로필로 먼저 엽니다.
장별 문제 주소도 함께 전달하며, 설치 앱이 없으면 기본 브라우저로 엽니다.
경계 페이지나 표지에서는 [장별 기출]로 장을 선택할 수 있으며,
옆 화살표로 해당 교재의 다른 장과 교재 말미 문제도 선택할 수 있습니다.
정확한 장별 연결이 없는 기출 회차/최빈출 파일은 [레일노트] 전체 문제로 연결합니다.
교재 읽기는 오프라인으로 가능하며 레일노트 문제는 인터넷 연결이 필요합니다.

두 쪽의 크기 맞추기
기본값은 [두 쪽] + [같은 크기]입니다.
[여백] 메뉴의 [페이지 크기]에서 크기 기준을 선택합니다.
같은 크기: 두 페이지를 동일한 크기의 틀에 넣습니다. 가로·세로 비율이
다르면 필요한 여백을 더하며, 내용이 잘리거나 늘어나지 않게 표시합니다.
같은 높이로: 페이지 높이를 똑같이 맞춥니다. 원본 비율에 따라 너비는 달라집니다.
원본 크기 비율: 원본 페이지 사이의 상대적인 크기 차이를 유지합니다.
[표지 따로]를 켜면 첫 페이지를 단독 표시하고, 다음부터 두 쪽씩 보여줍니다.

확대와 이동
상단 배율 퍼센트에 25~400%까지 1% 단위로 직접 입력합니다.
Ctrl을 누른 채 마우스 휠을 한 틱 움직이면 배율이 1%p씩 바뀝니다.
100%는 화면 맞춤 기준이며, 종이의 실제 인쇄 크기를 뜻하지 않습니다.
[너비 맞춤]을 선택한 경우에는 화면 너비에 맞춘 크기가 기준이 됩니다.
확대한 페이지는 스크롤해서 읽고, [화면 맞춤]을 누르면 다시 전체가 보입니다.
일반 스크롤이 현재 쪽의 맨 아래/위에 닿으면 그곳에서 먼저 멈춥니다.
연속 입력이 약 0.35초 이상 멎은 뒤 다시 아래/위로 스크롤하면 다음/이전 쪽으로 넘깁니다.
페이지를 넘긴 뒤 이어지는 관성 입력도 멈추므로 여러 쪽을 한꺼번에 건너뛰지 않습니다.
이전 쪽은 아래에서 이어 읽습니다. 화면에 모두 들어오는 쪽도 새 스크롤 입력마다 한 번만 넘깁니다.
목차와 설정 패널 안의 스크롤은 페이지를 넘기지 않으며 Ctrl+휠은 기존처럼 1%p씩 확대/축소합니다.
페이지 번호를 입력하면 원하는 쪽으로 이동합니다.
← / → 또는 Page Up / Down: 이전 / 다음 쪽
Home / End: 처음 / 마지막 쪽
＋ / − 또는 Ctrl + 마우스 휠: 확대 / 축소
0: 화면 맞춤   R: 회전   F11 / F: PDF 전체보기   Ctrl + O: PDF 열기
마지막으로 읽은 위치는 이 브라우저에 저장됩니다.
문서별 마지막 배율과 화면/너비 맞춤 기준도 함께 저장됩니다.
기록이 없는 새 문서는 가장 최근에 사용한 배율과 맞춤 기준으로 열립니다.
다시 실행하면 마지막 PDF를 찾아 저장된 위치에서 이어 읽습니다.
책장 PDF는 원본 파일을 다시 열며, [PDF 열기] 또는 끌어놓기로 연 일반 PDF는
자동 재개를 위해 이 PC의 브라우저 저장소에 마지막 한 개만 보관합니다.
브라우저 저장소를 지우거나 다른 브라우저를 사용하면 저장된 재개 정보는
이어지지 않습니다. 파일을 열 수 없으면 책장에서 다시 선택하세요.

화질
원본 PDF를 그대로 읽으며 압축하거나 다시 저장하지 않습니다.
스캔 페이지는 원본 이미지 픽셀을 기준으로 고해상도로 그립니다.
화면보다 큰 페이지는 고품질 축소 처리를 거쳐 디스플레이의 실제 픽셀 크기에
맞춥니다. 페이지 위치도 픽셀 경계에 맞춰 불필요한 추가 보간을 줄입니다.
[도구] → [⋯] → [화질 조절] → [축소 선명도]에서 글자 윤곽 보정 강도를 0~100으로
조절합니다. 기본은 [약하게](25)이며 [끄기](0), [중간](50)도 선택할 수 있습니다.
0에서는 윤곽 보정만 끄며 고품질 축소 처리는 유지됩니다.
설정은 다음 실행에도 유지됩니다. 원본 색상과 어두운 색상 모두에 적용됩니다.
축소 처리는 백그라운드에서 이루어지며 준비되면 표시가 선명해집니다.
큰 배율이나 매우 큰 페이지에서는 원본 렌더링을 우선해 메모리 사용을 제한합니다.
확대하면 해당 배율에 맞춰 다시 그립니다. 스캔 자체에 없는 세부 정보가
새로 생기는 것은 아닙니다.

가는 획 보강·글자 농도·배경 정리·여백 맞춤
[⋯] → [화질 조절]에서 획·농도·배경 보정을, [여백]에서 여백 조절을 개별적으로 켜고 끕니다.
처음에는 네 기능 모두 꺼져 있으며, 켜기/끄기와 조절값은 다음 실행에도 유지됩니다.
[가는 획 보강]: 원본 해상도에서 가는 중성색 획을 아주 약하게 보강한 뒤 축소합니다.
강도 0~100, 초기값 30. 0은 보정 없음이며 글자 농도·축소 선명도와 독립적입니다.
화면에 맞춰 줄여 표시할 때 적용되며, 매우 큰 배율에서는 보강 처리를 생략합니다.
강도를 높이면 작은 글자의 공간이 좁아 보일 수 있으니 낮은 값부터 비교해 보세요.
원본에서 사라진 글자나 끊어진 내용을 새로 만들어 복원하는 기능은 아닙니다.
[글자 농도 보강]: 가는 회색 획을 더 진하게 표시합니다. 농도 0~100, 초기값 30.
[배경 정리]: 밝은 저채도 종이 흔적을 줄입니다. 강도 0~100, 초기값 25.
두 기능 모두 0은 보정 없음입니다. 회색 도표나 옅은 표시가 흐려지면 강도를 낮추세요.
원본/어두운 색상 모두에서 동작하며 매우 큰 확대에서는 화질 보정이 제한됩니다.
[여백 제외하고 맞춤]: 각 페이지의 외곽 여백을 자동으로 찾고 본문 영역에 맞춥니다.
자동 여백 제거량 0~100은 인식한 여백을 얼마나 제외할지 조절합니다.
[쪽수·PART 꼬리말도 제외]: 본문과 떨어진 작은 하단 꼬리말과 그 위 공백도 제외합니다.
글자를 읽는 방식이 아니라 위치·크기·간격으로 판단하므로, 본문과 붙은 꼬리말은
남겨둘 수 있습니다. 사진·도표를 잘못 자르지 않도록 결과를 확인하며 사용하세요.
[여백 세부 조절]의 상하좌우 -15~+15%로 직접 보완할 수 있습니다.
＋는 원래 페이지 크기 기준으로 더 제외하고, −는 자동 제거한 여백을 복원합니다.
자동 제거량을 0으로 두면 수동값만 적용할 수 있습니다. 각 변과 전체 제거량에는
본문이 지나치게 잘리는 것을 막는 상한이 있습니다.
회전 후 수동 상하좌우는 현재 화면 방향 기준이며 자동 꼬리말은 원래 페이지 기준입니다.
기능을 끄면 페이지 전체가 복원됩니다. PDF 자체를 자르거나 다시 저장하지 않습니다.

읽기 색상
상단 색상 선택에서 원본 색상, 부드러운 회색, 따뜻한 회색, 사용자 색을 바로 선택합니다.
선택 상자 왼쪽의 [색상] 버튼으로 세부 색상을 조절합니다.
처음에는 눈부심을 줄인 부드러운 회색으로 시작합니다.
종이 배경색과 글자색, 강조색 강도를 직접 조절할 수 있습니다.
직접 조절한 배경·글자·강조색은 자동 저장되며 [사용자 색]에서 다시 불러옵니다.
기본 색상으로 바꾸어도 저장된 사용자 색은 유지되며 다음 실행에도 복원됩니다.
색상은 원본 해상도로 그린 화면에만 적용하며 원본 PDF는 바꾸지 않습니다.
스캔 문서는 사진·도표·강조 표시도 함께 변환됩니다. 원본 색 확인이
필요하면 [원본 색상]을 선택하면 즉시 돌아갑니다.

파일과 종료
PDF는 이 PC에서 처리되며 외부 서버에 업로드하지 않습니다.
원본 PDF의 내용·페이지 크기·회전·파일은 변경하지 않습니다.
창을 닫으면 읽기가 끝납니다. 로컬 서버는 빠른 재실행을 위해 배경에 남습니다.
실행.cmd를 다시 열면 기존 서버를 재사용합니다. PC를 종료하면 서버도 끝납니다.
서버까지 바로 종료하려면 작업 관리자의 [자세히]에서 [명령줄] 열을 켠 뒤,
이 폴더의 server.cjs가 명령줄에 표시된 node.exe만 선택해 작업을 끝내세요.
다른 프로그램이 사용하는 node.exe는 종료하지 마세요.

실행되지 않을 때
43187 포트를 다른 프로그램이 사용하면 잘못된 화면을 열지 않고 오류를 표시합니다.
Node.js가 필요하며, 설치된 Node.js 또는 이 PC의 Codex 제공 런타임을 사용합니다.
Codex 런타임을 삭제했다면 Node.js를 설치한 후 다시 실행하세요.
